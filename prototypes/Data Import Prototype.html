Data import

Groups and users are imported separately from CSV; re-importing updates existing records without losing history.

Salesforce group export. Each group gets an internal record and is matched to existing users for its Chair and Network Advisor — you confirm every match. Country is derived from Partner Code. A group is not launchable until both Chair and Network Advisor are mapped.

Required columns: EGN Group Name EGN Group Id MMSGroup: Name Partner Code Group Profile Member Profile Companies Profile Responsible Chair Responsible Sales (Responsible Sales = Network Advisor). CSV must be UTF-8; delimiter auto-detected.
