Import

Two independent import functions. Either can be run first, and either can be re-run at any time — re-importing updates existing records by EGN Group ID and never loses version history (spec §12).

Importing groups (the Salesforce export) and importing users & countries (Chair/NA/Chair Leader/Sales Leader + Country mapping) are separate functions with separate files. A group can be imported before, at the same time as, or after its user & country mapping — the Groups screen below simply flags which imported groups are still missing a mapping.

1. Import groups

Source: Salesforce group export (.xlsx). Re-importing updates existing groups by EGN Group ID without destroying version history.

Expected columns: EGN Group Name, Group Profile, Member Profile, Companies Profile, Chair Profile, Group Status, Responsible Chair, EGN Group Chair, EGN Group ID.
